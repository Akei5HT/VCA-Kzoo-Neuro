# VCA Kzoo Neuro
Neurology work-related

## Client handouts
Printable one-page client handouts (HTML + PDF) in `handouts/` — live at
https://akei5ht.github.io/VCA-Kzoo-Neuro/handouts/

Edit the Markdown in `handouts/src/`, then rebuild with `python3 handouts/build.py`
(needs pandoc, Google Chrome and `pypdf`). The build flags any handout over 2 pages.
